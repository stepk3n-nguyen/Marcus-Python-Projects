# 📚 BỘ 4 DỰ ÁN PYTHON LUYỆN TẬP TỔNG HỢP CHO MARCUS
## 4 Mini Python Projects for Comprehensive Practice

Bộ bài tập này được tinh chỉnh tập trung 100% vào các kiến thức nền tảng cốt lõi:
- **Hàm (`def`, tham số, `return`) / Functions (parameters, return values)**
- **Cấu trúc rẽ nhánh (`if`, `elif`, `else`) / Conditionals**
- **Vòng lặp (`for`, `while`, `break`) / Loops**
- **Toán tử cơ bản (`+`, `-`, `*`, `/`, `%`, so sánh và logic) / Basic operators**

> Tất cả các yêu cầu và chú thích trong từng project đều được trình bày **1 dòng Tiếng Việt** đi kèm **1 dòng Tiếng Anh** liền kề.
